# Hotel Booking Cancellation Prediction

A Cloud ML final-project API that predicts whether a hotel booking will be canceled.
The current model uses a stacking meta-classifier to combine XGBoost, CatBoost, and
Random Forest predictions.

The notebook at `notebooks/hotel_cancellation.ipynb` contains the EDA, preprocessing,
model comparison, stacking configuration, and saved-artifact generation. This README
covers local setup and AWS EC2 deployment.

## Project structure

```text
hotel-cancellation/
├── app/
│   ├── __init__.py
│   └── main.py                  # FastAPI application
├── data/
│   ├── raw/
│   │   └── booking.csv          # source dataset
│   └── processed/
│       └── booking_clean.csv    # cleaned dataset generated by the notebook
├── models/
│   └── stacking_model.joblib    # complete preprocessing and stacking pipeline
├── notebooks/
│   └── hotel_cancellation.ipynb
├── sample_requests/
│   └── predict.json
├── .gitignore
├── requirements.txt
└── README.md
```

Only `app/`, `models/`, `requirements.txt`, and `sample_requests/predict.json` are
needed to run the deployed API. Commit the saved model because EC2 does not retrain it.

## Requirements

- Python 3.12
- The model was trained and saved with the pinned package versions in `requirements.txt`
- An EC2 Linux instance with outbound internet access for package installation

## 1. Train locally or in Google Colab

Use Python 3.12 for the environment and package versions used to create the model.

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install pandas numpy scikit-learn xgboost catboost matplotlib seaborn
python -m pip install statsmodels joblib jupyter fastapi "uvicorn[standard]" pydantic
```

Start Jupyter and run every cell in `notebooks/hotel_cancellation.ipynb`:

```bash
jupyter notebook notebooks/hotel_cancellation.ipynb
```

The notebook generates:

- `models/stacking_model.joblib`
- `data/processed/booking_clean.csv`
- `sample_requests/predict.json`
- `requirements.txt`

Rerun the training notebook whenever you change the selected features or model
configuration. Keep the notebook-generated `requirements.txt` aligned with the same
library versions used to save the model.

## 2. Run the API locally

Install the deployment dependencies:

```bash
python -m pip install -r requirements.txt
```

From the project root, start Uvicorn:

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Available endpoints:

- `GET http://localhost:8000/health`
- `POST http://localhost:8000/predict`
- `GET http://localhost:8000/docs`

Test the prediction endpoint from Windows PowerShell:

```powershell
$body = Get-Content -Raw sample_requests/predict.json
Invoke-RestMethod `
  -Uri "http://localhost:8000/predict" `
  -Method Post `
  -ContentType "application/json" `
  -Body $body
```

Example response:

```json
{
  "prediction": "Not_Canceled",
  "cancel_probability": 0.0631,
  "base_model_probabilities": {
    "XGBoost": 0.079,
    "CatBoost": 0.0441,
    "Random Forest": 0.1107
  }
}
```

The response probability is the cancellation probability. Values of `0.5` or greater
return `Canceled`; values below `0.5` return `Not_Canceled`.
